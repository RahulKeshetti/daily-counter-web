## 📖 Project Overview
Small shop owners and retail counters often struggle with paper notebook ledgers, unrecorded credit dues, and manual payment chasing. **DailyCounter** provides a simplified mobile-first interface to log sales, record customer credit balances, and automate payment reminders.

This landing page was developed as a milestone deliverable, meeting all content specifications and scoring criteria:
- Fully responsive across mobile, tablet, and desktop displays with zero horizontal scrolling.
- Single unified typeface pairing with consistent rhythm and spacing scales.
- Smooth transitions, floating card elevations, and hover states on all interactive elements.
- Accessible markup with clean semantic tags and descriptive image `alt` attributes.
- Clean console execution with zero CDN or script errors.

## ✨ Key Sections
1. **Sticky Navigation Bar:** Wordmark logo, responsive collapse hamburger menu, section anchor links (*Features*, *Testimonials*, *How It Works*), and an actionable CTA button.
2. **Hero Section:** Value proposition headline, descriptive subheadline, dual action buttons (*Start Free*, *How It Works*), and an optimized responsive hero graphic.
3. **Features & Benefits:** 4 interactive cards covering the Digital Ledger, Auto Reminders, Daily Summary, and Cloud Backups with smooth hover lifts and accent icons.
4. **Social Proof (Testimonials):** 3 genuine customer reviews from local retail and general store owners highlighting reduced credit cycles.
5. **How It Works (3-Step Process):** Clear, numbered walk-through illustrating customer import, transaction logging, and automated reminder alerts.
6. **Closing CTA Section:** High-contrast dark navy banner with primary gold CTA button to drive sign-ups.
7. **Footer:** Clean footer with navigation links (*About*, *Contact*, *Privacy*), interactive social media icons, and copyright details.

## 🎨 Design System

### Color Palette
| Element | Hex Code | Purpose |
| :--- | :--- | :--- |
| **Primary** | `#14367a` | Primary brand blue, headers, active states, CTA container |
| **Accent** | `#f2a900` | Warm amber gold for buttons, highlights, and borders |
| **Hover Accent** | `#d99400` | Deeper gold tone for button hover states |
| **Neutral Dark** | `#323f4b` / `#0d2436` | Main body text and footer background |
| **Neutral Light** | `#f1f4fa` | Alternating section backgrounds for visual structure |
| **Card Borders** | `#e5eaf4` | Subtle card outlines and divider rules |

### Typography & Polish
- **Primary Font:** [Roboto](https://fonts.google.com/specimen/Roboto) (300, 400, 500, 700) via Google Fonts.
- **Transitions:** `all 0.25s ease` applied globally across anchors, buttons, and elevation cards.
- **Micro-Interactions:** Subtle card lifts (`transform: translateY(-4px)` to `-5px`) with ambient shadows (`box-shadow: 0 12px 24px rgba(20, 54, 122, 0.1)`).

## 🛠 Tech Stack
- **HTML5:** Semantic structure and accessible layouts.
- **CSS3:** Custom styles, CSS variables, transitions, and media query overrides.
- **Bootstrap 4.5.2:** 12-column grid system, container alignment, and navigation toggler.
- **Font Awesome 5:** Stable CDN vector icons.
- **Deployment:** [Netlify](https://www.netlify.com/) continuous static deployment.

## 📱 Responsive Breakpoints Tested
- **Mobile (375px):** Stacked full-width buttons, scaled typography, single-column cards, zero horizontal overflow.
- **Tablet (768px):** 2-column feature card grid, optimized spacing, collapsible mobile drawer.
- **Desktop (1280px+):** 4-column feature row, 3-column testimonial and step cards, fully expanded horizontal navbar.
